# 🚗 SmartPark – Local Train Parking Management App

SmartPark is an Android application designed to digitize and simplify **local train parking operations**. It helps parking vendors manage daily parking activities, track users, generate tickets, and maintain records efficiently.

---

## 📌 Project Overview

SmartPark replaces manual parking systems with a digital solution that handles:
- Vehicle entry & exit
- Ticket generation
- Payment tracking
- History management

The project is being developed in **phases**, starting with vendor-side features and expanding into a **user-friendly parking system**.

---

## 🚀 Phase 1 – Vendor Management System (Completed)

### 🔹 Features

- ✅ Vendor Registration
- ✅ Daily Parking User Management
- ✅ Monthly Pass User Handling
- ✅ Entry & Exit Tracking

### 💰 Pricing Logic
- ₹20 → First 12 hours
- ₹10 → Next 12 hours

### 💳 Payment Options
- Cash
- UPI (manual entry)

### 🎟 Ticket System
- Generate parking ticket instantly
- Print via Bluetooth Printer
- Share via WhatsApp

### 📊 Records & History
- Maintain complete parking logs
- Daily transaction tracking
- User history management
